## 阶段 0：管线规范化 + 材质通用化实测

**为什么先做这段**：它是整个方案的地基。如果材质做不到通用，那"材质共享、只切配色和背景"的产品设想就不成立，后面全部要改。**必须先证伪或证实，再写别的代码。**

### 0.1 收拢

```
projects/hana-skin-app/patch/     ← 补丁管线（从 pack-luna5 迁入）
├── scripts/     apply / check / restore
├── src/         五套主题源（配色 / 材质 / 背景 / 取景框）
├── patches/     5 处注册表与调色板补丁
└── VERSION
```

**验收**：`apply.ps1` 在新位置干跑通过（退出码 0）。

### 0.2 清残留色值

Luna 的材质与背景里还有 8 处月满庭色值（`#172725` / `rgba(23,39,37,·)`）。
**验收**：全仓 grep 这两组值，在 `material-luna/`、`background-luna/` 里为 0。

### 0.3 材质通用化（核心实验）

改造对象：把"每主题一份材质"变成"一份通用材质"。

1. 新建 `src/material-universal/{bold,subtle}.css`
2. 选择器 `[data-theme="hana-moonlit-court"]` → `[data-theme^="hana-"]`
3. 16 处写死 hex → 换成对应 `var(--…)`
4. `apply.ps1` 让所有主题引用同一份材质源

**判据（必须全部成立才算通过）：**
- 合成后的 5 个主题 CSS 里，材质规则的选择器都是 `[data-theme^="hana-"]`
- 材质规则里不再有写死的主色调（只剩 `#000` 阴影这类中性值）
- 干跑通过，主题数仍 16

### 0.4 视觉验证（需用户）

贴入 → 用户重启 → 在 5 个主题间切换，确认：
- 毛玻璃、描边在**每个**主题上都在
- 没有被官方样式盖掉（这是最大的失败模式：特异性不足）

**若失败**：退回"每主题一份材质"，并把结论写进文档，同时重新评估 T1 是否改回 B。

### 0.5 结论

写回 `REQUIREMENTS.md`：材质通用成立 / 不成立，及对后续阶段的影响。
